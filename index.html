Projects

Three things I shipped.

One iOS app I trained a marathon on, one tool that cleans up after data scientists, and one server that gives Claude a research library.

01

Circular

Swift · iOS GitHub
  • Generates running routes to a target distance within ±0.1 mile, using MapKit, CoreLocation and Mapbox under a two-edges-per-waypoint geospatial constraint.
  • Cut API load 50% and route-generation attempts 40% by rewriting the search scaling, with no loss in accuracy.
  • Grew a 100+ user beta from 10,000+ views across YouTube and Instagram, and shipped changes from what the first ten testers actually complained about.
SwiftMapKitCoreLocationMapbox
02

nb2prod

Python GitHub
  • Turns a messy Jupyter notebook into a production-ready Python project, dropping deployment from hours to minutes.
  • Scores production readiness 0–10, validates execution order, and uses Claude to generate documented, error-handled code — available as both a CLI and a Streamlit app.
  • Multi-phase refactoring pipeline built on AST analysis plus LLM enhancement, covered by 25+ automated tests.
PythonClickClaude APIStreamlitAST
03

arXiv MCP Server

Python · MCP GitHub
  • Gives Claude and Cursor a persistent, semantically searchable arXiv library instead of a fresh context every session.
  • Dual-storage architecture — SQLite plus ChromaDB with local embeddings — searching across 39K+ characters of extracted PDF text.
  • Fifteen tools covering the full research loop: import, fulltext search, annotation extraction, preprint-to-DOI tracking via Semantic Scholar and Crossref, duplicate detection, and KMeans topic clustering.
